# 🔐 Gerador de Senhas com Tkinter

Este é um simples gerador de senhas desenvolvido com Python e Tkinter. Ele permite ao usuário personalizar senhas seguras de maneira prática e visual.

## 🖼️ Interface Gráfica

O aplicativo possui uma interface gráfica amigável feita com Tkinter, com os seguintes recursos:

- Definição do comprimento da senha (de 8 a 32 caracteres)
- Inclusão opcional de:
  - Letras maiúsculas
  - Números
  - Caracteres especiais
- Geração de senha com um clique
- Mensagens de erro caso nenhuma opção de caractere seja selecionada
- Botão de saída
